# The name "Michael Clay" comes off display, for now

Ruling: GD, 2026-11-28.

> "remove for now and let's keep our eye on that."

The question he answered (the Christmas walk-through, decision 5): "Michael Clay" shows as a
displayed name on 2kleigh.com videos and on gputnammusic.com/videos. Allowed, or remove?

## What this means

- The displayed name "Michael Clay" is removed from public pages. Where the name is only a
  caption or heading, the name goes and the video or song stays.
- "For now": this is a hold, not a permanent rule. "Keep our eye on that" means it is to be
  raised with GD again, not lifted by anyone else.
- Records that are not display (legal, financial, ASCAP, code comments, provenance) are not
  touched by this ruling.

## Done in gputnammusic.com (this repository), 2026-11-28

- `/videos`: the section heading "Michael Clay" now reads "KLEIGH". All seven videos stay,
  playing from 2kleigh.com exactly as before.
- `/kleigh` (components/KleighT20Grid.tsx): the four instrumentals showed "Michael Clay" as
  the now-playing name; they now show "Kleigh". The songs stay.
