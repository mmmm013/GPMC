# GPMC INSTRO Display Title Standard

Status: TITLE NORMALIZATION STANDARD  
Authority: GPMC / GPMC-C  
Date: 2026-06-24

## Rule

All instrumental / INSTRO display titles use this format:

Clean Track Title - INSTRO

## Do Not Display In Title

- artist names
- BPM
- key
- source filename clutter
- file-tech descriptors

## Metadata Fields

BPM, key, creator / artist attribution, source filename, and source path belong in metadata/provenance fields, not display title.

## Example

Source filename:

home-is-sunny-instro-84-5bpm-cminor.wav

Display title:

Home Is Sunny - INSTRO

Metadata:

BPM: 84.5  
Key: C minor  
Type: INSTRO
