Status: TITLE NORMALIZATION RECORDED  
Authority: GPMC / GPMC-C  
Date: 2026-06-23

## Result

Display title: Back to the Water  
Creator / artist attribution: Michael Clay  
Public title contains artist name: NO

## Reason

The prior source filename contained an artist-name prefix. KKr/GPMC title normalization removes artist-name prefixes from display titles.

In this case, the title was also improved to Back to the Water.

## Control

This change updates public display/title records only.

This change does not create a final Track ID.

This change does not create a PIX.

This change does not create an LT-PIX.

This change does not approve public use.

The prior source filename/provenance is retained in the private audio vault manifest and should not be used as the public display title.

## Doctrine

Artist / creator names belong in attribution fields.

Display titles should not carry artist-name prefixes.
